`Prose` applies article-style typography (headings, paragraphs, lists, links, code, blockquotes) to everything inside it, scoped to the subtree and themed via CSS vars. Wrap rendered rich text — including the editor's `Reader` output — in `Prose` instead of importing a global prose stylesheet.

## API Reference

`Prose` — `size` (`sm` | `base` | `lg`, default `base`); React also takes `as` (element tag, default `div`), Svelte takes `element`. Forwards `className`/`class`.
