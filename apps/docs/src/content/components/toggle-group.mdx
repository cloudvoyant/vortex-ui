`ToggleGroup` groups related `ToggleGroupItem` toggles with shared selection state. Built on [Ark UI `toggle-group`](https://ark-ui.com/docs/components/toggle-group), sourced from [Shark UI](https://shark.vini.one/docs/components/toggle-group). Pass `multiple` for multi-select and `attached` for a segmented look.

## API Reference

`ToggleGroup` — `value` / `defaultValue` (`string[]`), `onValueChange`, `multiple`, `disabled`, `orientation` (`horizontal` | `vertical`), `attached`.

`ToggleGroupItem` — `value` (required), `variant` (`default` | `outline`), `size` (`default` | `sm` | `lg`), `disabled`.
